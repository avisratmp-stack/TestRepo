# Ping Pong Game

A classic ping pong (Pong) game implemented in Python using Pygame.

## Features

- Two-player gameplay
- Simple and intuitive controls
- Score tracking
- Smooth ball physics with paddle collision detection
- Classic retro design

## Installation

1. Install Python 3.7 or higher
2. Install dependencies:
```bash
pip install -r requirements.txt
```

## How to Play

Run the game:
```bash
python ping_pong.py
```

### Controls

- **Left Paddle (Player 1)**: W (up) / S (down)
- **Right Paddle (Player 2)**: UP arrow (up) / DOWN arrow (down)
- **Quit**: ESC or close window

### Rules

- The ball bounces off the top and bottom walls
- Score a point when the ball passes your opponent's paddle
- The ball speed varies based on where it hits the paddle
- First to reach the desired score wins!

## Enjoy the Game!

Have fun playing this classic arcade game with a friend!
